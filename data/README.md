# Geospatial & Hydrological Datasets - Varun (SIH26085)

This directory contains curated geospatial layers, digital elevation models, drainage networks, and historical flood inundation archives for Delhi NCR.

## Dataset Files

1. `delhi_flood_zones.geojson`: High-risk flood hotspots, catchment definitions, impervious surface percentages, soil types, and critical municipal infrastructure.
2. `delhi_drainage.geojson`: Primary trunk drains and storm sewers with discharge capacities ($m^3/s$), cross-sectional geometry, slope gradients, and siltation factors.
3. `delhi_roads.geojson`: Road network topology formatted for NetworkX graph routing with base elevation, underpass classifications, and emergency evacuation status.
4. `delhi_elevation_grid.geojson`: Digital Elevation Model (DEM) 2D grid covering Delhi NCR topography (190m to 260m ASL).
5. `historical_events.json`: Historical monsoon waterlogging records detailing previous depths, affected zones, and root causes.
